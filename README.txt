ВАЖНО: загружай ФАЙЛЫ ИЗ ЭТОЙ ПАПКИ в корень GitHub-репозитория, а не саму папку целиком.

В корне репозитория должны лежать:
index.html
style.css
script.js
manifest.json
sw.js
icons/

После загрузки обнови GitHub Pages. Если старая версия остаётся на iPhone, закрой вкладку/удали ярлык и открой сайт заново; Service Worker использует новую версию cache.
